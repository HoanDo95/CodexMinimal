# Phase Flow

1. Read approved spec.
2. Confirm required quality gates from the IDSD agent cards: solution challenge, system design, senior QA, reviewer, or verifier.
3. Write or refresh phase plan.
4. Write or refresh tracker.
5. Refresh artifact registry and current-work state.
6. Determine current phase.
7. Handoff the current phase to Codex CLI native execution by default, or to another selected adapter when policy requires it.
8. Collect verification and QA gate status from execution.
9. Update tracker and telemetry.
10. Stop before the next phase until status is clean.
