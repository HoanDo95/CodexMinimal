# AGENTS.md Template Rules

AGENTS.md should be short, durable, and operational.

It should contain:
- pre-task routing
- model routing principles (no hardcoded model names)
- skill selection policy
- context budget
- search policy with project index usage
- testing specification
- protected files policy
- user rule mutation policy

Do not use AGENTS.md as a long knowledge dump.
Put detailed knowledge into `docs/ai` or skill references.
